# Obsidian + Codex 个人知识库模板

一套由 Obsidian 阅读和编辑、由 Codex 协助整理与维护的个人知识库模板，适用于工作、个人与学习场景。

本仓库分享目录结构和管理规则。所有目录说明均为通用示例，不包含个人笔记。

## 开始使用

1. 点击 GitHub 的 **Code → Download ZIP**，解压到希望保存知识库的位置。
2. 在 Obsidian 中选择“打开文件夹作为仓库”，打开解压后的文件夹。
3. 在 Codex 中打开同一个文件夹，发送：

   > 请阅读根目录的 AGENTS.md，按这套规则协助我管理知识库。先介绍目录职责和需要我确认的操作。

如果仓库启用了模板功能，也可以点击 **Use this template** 创建自己的仓库，再下载或克隆到电脑。个人笔记请按自己的需要保存在本地或私有仓库中。

## 目录结构

| 目录 | 用途 |
| --- | --- |
| 00-速记 | 临时待办、随手想法、待分类记录 |
| 10-项目 | 有明确目标和完成条件的事项 |
| 20-领域 | 需要长期维护的责任与事项 |
| 30-资产 | 可复用的知识、方法、模板、案例与手册 |
| 40-资源 | 外部参考资料和证据 |
| 50-灵感 | 值得保留但尚未承诺执行的想法 |
| 60-技能 | Codex 可重复执行的标准流程 |
| 90-归档 | 已完成、暂停、失效或不再活跃的内容 |

完整分类判断、操作原则和权限边界见 [AGENTS.md](AGENTS.md)。本说明不替代治理规则。

## 常用指令

- “检查 00-速记，搜索同主题笔记，生成分类建议报告，先不要移动文件。”
- “搜索关于会议准备的现有资产，汇总可复用的方法，并注明来源。”
- “汇总知识库中的未完成 Markdown 待办，保留每条待办的原笔记链接。”
- “检查本周项目记录，生成复盘草稿，并提出可沉淀为资产的内容。”

## 工作方式

速记与资源 → 整理和核验 → 资产 → 项目应用 → 项目复盘 → 更新资产与技能。

默认优先生成可审阅的建议或报告。删除文件、改写重要结论、批量移动、修改治理规则等操作，需要按 AGENTS.md 先获得确认。

## 关于 Skill

这是一份知识库模板，无需安装 Skill 即可使用。根目录 AGENTS.md 用于提供知识库规则；60-技能用于记录流程，当前版本没有附带可安装的 Skill。

## 个性化与更新

首次使用时可以根据自己的情况审阅并调整规则。模板以后有更新时，先对比变化，再决定是否采用；不要直接覆盖已经积累的笔记和个性化规则。
